# Data Licensing & Attribution / 数据许可与归属

### Summary

The GraphInstruct benchmark mixes **freshly-synthesized data** (which we release under CC-BY-4.0) with **subsets derived from publicly available graph datasets** (each retaining its upstream license). Per-source attribution and license information is provided below.

### License of the freshly-authored components

| Component | Files | License | Why this license |
|-----------|-------|---------|------------------|
| Hand-authored instructions | `data/instructions/level_*.json` (800 instructions, 40 templates) | **CC-BY-4.0** | Permits research, derivative work, and commercial use with attribution. |
| Algorithmically synthesized reference graphs (L0–L2 + L5) | `reference_solutions` field embedded in `data/instructions/*.json` | **CC-BY-4.0** | Generated by NetworkX / `random_labeled_tree` / k-core peeling / etc. |
| L3 synthetic distributional pool | `data/reference_pools/l3_synthetic/*.pkl` (3,115 graphs over 15 attribute subgroups) | **CC-BY-4.0** | All graphs synthesized by us via calibrated parameter sampling. |

### License of the L4 real-world reference subset

We redistribute under the most permissive terms compatible with research use; please consult the upstream source if you intend commercial redistribution.

### Notes

- All L4 graphs are **size-normalized, deduplicated, and stripped of node/edge attributes other than what is required by D2/D3** to comply with privacy and re-identification guidelines.
- No personally identifiable information (PII) is present in any redistributed subgraph.
- The Reddit subset retains anonymized subreddit identifiers (no usernames or post content).
- The DBLP subset retains author identifiers (publicly indexed by DBLP) but no full names beyond the public DBLP indexing.

### How to cite

If you use the GraphInstruct benchmark, cite the main paper (BibTeX in `README.md`). If you specifically use the L4 real-world references, please **also cite the upstream sources** listed above as appropriate.
